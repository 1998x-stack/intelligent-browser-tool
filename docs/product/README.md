# Evidence Radar — Product Research and PRD

This is a **documents-only product proposal** for the next user-facing direction of intelligent-browser-tool. It does not imply that a hosted web product, subscription or production browser-security certification currently exists.

## What has been learned versus what remains hypothetical

**Observed feedback:** complex workflow reliability issues, slow support, need for cross-source enrichment, cost caps, deterministic replay, monitor organization, RSS/email delivery choices, security and OSS attribution concerns.

**Market baseline:** Firecrawl, Browse AI, Visualping, Skyvern and changedetection.io already cover large parts of scraping, agent execution and website-change monitoring. Firecrawl launched /monitor in 2026, so those features alone should not be framed as unique.

**Proposed differentiator, still unvalidated:** a continually updated **evidence-linked research dossier** with contradiction/unknown handling, exact source snapshots, controlled reruns and explicit budgets.

## Next independent judge

Prioritize real task observation: a user must generate, inspect and act on an evidence-backed competitor brief faster and with no higher error rate than their current method. A Product Hunt ranking is not the product-quality test.
